# Gravity VR

An educational virtual reality experience that teaches the abstract concept of gravity through three scenes (Moon and Earth, Solar System, Black Hole) and an in-headset quiz. Built for the Meta Quest 2 as my CM3070 Final Project.

## Built with
- Unity 6000.3 
- Universal Render Pipeline
- XR Interaction Toolkit
- Target platform: Android (Meta Quest 2)

## Where to find the code
All of my own scripts are in `Assets/Scripts`. Scenes are in `Assets/Scenes`.

## How to open
1. Download or clone this repository.
2. Open it with Unity Hub using the Unity version above.
3. Import the assets listed above.
4. Open `Assets/Scenes/MainMenu` and press Play, or build to a Quest 2.
